# Plano de implementação dos experimentos

Este plano transforma a [avaliação crítica](../avaliacao-de-tudo/AVALIACAO_CRITICA.md) em uma arquitetura e uma sequência de entregas rastreáveis. Ele organiza o trabalho proposto; o pipeline científico, os dados originais e os resultados ainda não foram entregues.

1. Leia [ARQUITETURA.md](ARQUITETURA.md) para entender as responsabilidades, a interface pretendida e as regras para gráficos.
2. Use [BACKLOG.md](BACKLOG.md) como fonte única do andamento da implementação. Atualize os itens e suas evidências conforme as entregas forem concluídas.
3. Siga [AGENTS.md](../../AGENTS.md) para preservar alterações existentes e registrar commits de unidades concluídas.

Os documentos em `docs/Material-original/` e `docs/Revisao-gustavo/` são fontes históricas. A avaliação crítica interpreta essas fontes; o backlog descreve o trabalho futuro. Divergências científicas devem ser resolvidas com evidências e registradas, sem reescrever a história das fontes.
