# Projeto: Detecção de Conflitos para Governança Territorial
**Livro Alvo:** AI-Driven Territorial Governance for Effective Public Decision-Making (IGI Global)
**Status Atual:** Proposta aprovada em 06/09/2026, com cinco exigências editoriais a cumprir no capítulo completo.

## Visão Geral
Este projeto expande a pesquisa original sobre detecção de violência em vídeos (utilizando CNNs, BiLSTM e Attention Mechanisms) para o contexto de políticas públicas, cidades inteligentes e prontidão algorítmica. O foco principal é avaliar como a infraestrutura de dados municipal pode integrar redes neurais para atuar como sistemas de suporte à decisão.

## Estrutura do Projeto
- O modelo base alcançou acurácia de 96.50% com MobileNetV2 + BiLSTM.
- A expansão metodológica foca na integração dessa tecnologia em Dashboards de BI e dispositivos de borda (Edge AI).
