# Dados originais

Coloque aqui os arquivos originais recebidos, sem modificá-los. Para obter a versão 1 do RLVS identificada pelo pesquisador, siga as instruções de autenticação e download em `docs/GUIA_DE_USO.md`. O script grava os dados em `rlvs-v1/` com um arquivo de metadados e sem sobrescrever downloads existentes. Registre licença/condições de uso e documentação dos rótulos. Este conteúdo é ignorado pelo Git; não envie dados para este repositório.
